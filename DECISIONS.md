# Project Decisions

## Initial Decisions

1. Launch the first version in Addis Ababa, Ethiopia.
2. Build the frontend with React, TypeScript, Vite, and Bootstrap 5.
3. Build the backend with Django REST Framework.
4. Use PostgreSQL for the database.
5. Use Axios and TanStack Query for API communication and server-state management.
6. Use Django Admin to manage listings in Version 1.
7. Allow renters to contact advertisers by phone.
8. Exclude authentication, payments, messaging, maps, and custom landlord dashboards from Version 1.
9. Build and test the backend API before connecting the frontend.
10. Keep the implementation beginner-friendly and avoid unnecessary complexity.

Update this file whenever a lasting architectural or product decision changes.
